'number' + 3 + 3 
Коли ми додаєм рядок з числами то відбудеться конкатенація. Результат буде - 'number33'

null + 3 
Буде 0+3=3 бо null це 0

5 && “qwerty"
Буде “qwerty”, бо останнє значення це рядок, а перше значення =true,  тож в такому кейсі його покаже

+'40' + +'2' + “hillel”;
Унарний плюс перетворює рядок на число. Тому спочатку числа 40 і 2 ми додаєм(бо вони стали числами завдяки унарному плюсу), а потім ми робим конкатенацію з рядком і вийде '42hillel'

'10' - 5 === 6;
Рядок ’10' стане числом, відбудеться віднімання. Залишиться 5, а 5 не дорівнює 6 (там строге дорівнює, тому порівнюєм саме значення) Отже відповідь - false

true + false
true = 1, false = 0 1+0 = 1

'4px' - 3
Буде NaN. Бо ми не можемо привести рядок до числа якщо там є щось крім числа, тож ми не можем виконати віднімання в такому разі

'4' - 3
Буде =1. Бо ‘4' ми прирівнюєм у число(бо коли це віднімання то рядок в цьому випадку стане числом) і після віднімання залишиться 1

'6' + 3 ** 0; Буде ’61’. Бо 3 в степені 0 це 1. Конкатенація рядка і числа відбудеться 


12 / ‘6' Результат = 2. Так само, при діленні рядок стає числом

'10' + (5 === 6);
5 не строго дорівнює 6 - тож буде false. Строка ’10' і конкатенація з false = ‘10false’


null == ‘’
Результат = False. Бо null і ‘’ це різні типи данних 

3 ** (9 / 3);
Результат = 27. Спочатку ділим 9 на 3 =3. Потім 3 возводим у ступінь 3

!!'false' == !!’true’
Буде = True. Бо обидва значення True (бо це не пусті строки)



0 || '0' && 1
Буде = 1. ‘0' && 1 = повернеться 1 (бо воно останнє обчислене значення). 0 || 1 = повернеться 1 (бо воно truthy)

(+null == false) < 1;
Буде = False. Бо (+null == false) = (0=0) -> True. А True =1. Тож 1<1 = False


false && true || true Результат - True. false && true = False. false || true = True (бо потрібно щоб хоч одне значення було тру при ||)

false && (false || true);
Буде = False. Спочатку виконуєм е що у дужках (false || true) = True. Потім false && true = False (бо при && щоб повернулось тру має все бути тру, а тут одне значення фолс, тож його повертаєм)

(+null == false) < 1 ** 5;
Буде = False. Спочатку виконуєм е що у дужках (+null == false) = true. Потім возводим у ступінь 1 ** 5 =1. А 1>1 = False
